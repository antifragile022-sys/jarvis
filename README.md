# Jarvis-RU · голосовой ассистент в стиле Джарвиса

Локальный (оффлайн) голосовой ассистент на Python для **Windows**, понимает
**русский язык**, плюс умеет действовать на компьютере как агент через **Google
Gemini** (с function calling).

> Готовый `.exe` лежит во вкладке [**Releases**](https://github.com/antifragile022-sys/jarvis-ru/releases).
> Просто скачай, запусти — при первом старте откроется окно настроек, куда
> нужно вписать ключ Gemini.

---

## Что умеет

### Локальные команды (не дёргают API — работают всегда)
- открыть/закрыть приложения: `браузер`, `блокнот`, `калькулятор`, `проводник`, `вс код`, `эксель`, `outlook`, `discord`, …
- открыть сайт: `открой ютуб`, `открой гитхаб`, `открой яндекс`
- поиск: `загугли как варить борщ`, `найди на ютубе AC/DC`
- громкость: `громкость 50`, `сделай громче`, `тише`, `выключи звук`, `на максимум`
- яркость: `яркость 80`, `ярче`, `темнее`
- время / дата: `сколько времени`, `какое сегодня число`, `какой день недели`
- погода: `погода в Москве`, `какая погода`
- системная инфа: `загрузка процессора`, `сколько памяти`, `сколько заряда`, `состояние компьютера`
- скриншот: `сделай скриншот`
- питание: `заблокируй компьютер`, `усыпи`, `перезагрузи`, `выключи компьютер`, `отмени выключение`
- настройки: `открой настройки`, `смени ключ`

### Агент-режим (через Gemini)
Если ни одна локальная команда не подошла — Джарвис передаёт фразу в Gemini.
Если включён **агент-режим** (по умолчанию), Gemini может вызывать инструменты:

| Инструмент       | Что делает                                                  | Требует подтверждения? |
|------------------|-------------------------------------------------------------|------------------------|
| `open_app`       | Запуск приложения                                            | нет |
| `open_url`       | Открыть URL                                                  | нет |
| `search_web`     | Гугл-поиск                                                   | нет |
| `set_volume`     | Громкость 0-100                                              | нет |
| `set_mute`       | Mute / unmute                                                 | нет |
| `set_brightness` | Яркость 0-100                                                | нет |
| `take_screenshot`| Скриншот в папку                                              | нет |
| `system_info`    | CPU / RAM / диск / батарея                                    | нет |
| `read_file`      | Прочитать файл                                                | нет |
| `list_dir`       | Список файлов                                                 | нет |
| `write_file`     | Создать/перезаписать файл                                     | **да** |
| `run_shell`      | Команда PowerShell / sh                                        | **да** |
| `run_python`     | Исполнить Python-сниппет                                       | **да** |
| `type_text`      | Эмуляция клавиатурного ввода                                   | **да** |
| `press_keys`     | Комбинации клавиш (`ctrl+c`, `win+d`, …)                      | **да** |
| `lock_workstation`/`shutdown_pc`/`cancel_shutdown` | Питание         | для `shutdown` — да |

При первом опасном действии вылетает Tk-диалог «разрешить?». В настройках можно
включить **«выполнять без подтверждения»**, если ты понимаешь риски.

## Установка `.exe` (Windows)

1. Скачай `Jarvis.exe` из [Releases](https://github.com/antifragile022-sys/jarvis-ru/releases).
2. Запусти. При первом старте откроется окно настроек:
   - вставь **Gemini API Key** (получить: <https://aistudio.google.com/app/apikey>);
   - нажми «**Проверить ключ**» — Джарвис скажет «OK», если всё в порядке;
   - выбери модель (по умолчанию `gemini-2.5-flash-lite` — самая экономная);
   - сохрани.
3. Скажи «**Джарвис, какая погода**» или «**Джарвис, открой ютуб**».

> Vosk-модель русского языка (~45 MB) уже **встроена** в `.exe`. Никаких
> отдельных скачиваний не нужно. Первый запуск может занять 10-15 секунд —
> Windows распаковывает контент.

### Сменить ключ позже
- голосом: **«Джарвис, открой настройки»** или **«смени ключ»**
- из консоли: `Jarvis.exe settings`
- автоматически: если Gemini вернёт «квота исчерпана» — окно настроек откроется само.

### Где лежат настройки
`%APPDATA%\Jarvis\config.json` — переносимый JSON-файл. Можешь редактировать руками или удалить, чтобы вернуться к настройкам по умолчанию.

## Установка из исходников

```powershell
git clone https://github.com/antifragile022-sys/jarvis-ru.git
cd jarvis-ru
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python scripts/fetch_model.py --model small
python -m jarvis
```

### Команды CLI
```powershell
python -m jarvis              # голосовой режим
python -m jarvis text         # текстовый режим (без микрофона)
python -m jarvis once "X"     # одна команда и выход
python -m jarvis settings     # окно настроек
python -m jarvis voices       # список TTS-голосов
python -m jarvis devices      # список аудио-устройств
```

## Экономия квоты Gemini

В дефолтной конфигурации квота расходуется минимально:
- модель — самая дешёвая (`gemini-2.5-flash-lite`);
- системный промпт короткий;
- **локальные команды никогда не идут в Gemini** (время, громкость, скриншот и т.д. обрабатываются на месте);
- одинаковые вопросы кэшируются в памяти (LRU);
- при ошибке 429 ассистент тут же предлагает сменить ключ.

В настройках можно выбрать более «умную» модель: `gemini-2.5-flash` / `gemini-3.5-flash` — будут отвечать лучше, но дороже.

## Архитектура

```
голос → Vosk (оффлайн) → строка
           ↓
   wake-word детектор («Джарвис, …»)
           ↓
   локальный роутер интентов (regex) ───► выполнить сразу, ответить через TTS
           ↓ (если ни одна команда не подошла)
   Gemini-клиент (агент-режим: function calling)
           ↓                  └─► вызовы агент-инструментов (open_app, run_shell, …)
   ответ строкой → pyttsx3 (SAPI5) → голос
```

Файловая структура:
```
jarvis/
├── __main__.py        CLI
├── assistant.py       цикл «STT → роутер → LLM → TTS»
├── config.py          объединяет settings_store + env
├── settings_store.py  чтение/запись %APPDATA%/Jarvis/config.json
├── stt.py             Vosk + текстовый ввод
├── tts.py             pyttsx3
├── wakeword.py        детектор wake-word
├── router.py          regex-маршрутизатор интентов
├── llm.py             Gemini-клиент (google-genai SDK)
├── agent_tools.py     инструменты для function-calling
├── gui/settings.py    Tkinter окно настроек
└── skills/            локальные навыки (apps, volume, weather, ...)
```
